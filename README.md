# Pixistory (PixistoryAS)

Android app for collecting and keeping track of your devices, with Pixel history, specs, Pixel Drops and known faults.

**Status: work in progress. This snapshot does NOT build yet.**

Done so far: Gradle setup, Room database, settings, Google sign-in + Firestore sync, AI client (Claude / Gemini), analytics, export / backup, patch alerts, fold-state detection, Pixel knowledge data (English + Urdu), Pixel Drops data with per-feature compatibility, logo and icons, launch pop-up, About screen.

Still missing: most screens (devices, editor, detail, Pixel Drops, analysis, Ask Pixi, settings, shelf, root navigation) and the English / Urdu string resources.
